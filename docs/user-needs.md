# ユーザーニーズ整理

## ターゲットユーザー

- 自分自身（個人利用）
- 音楽好き。新しい曲との出会いを楽しんでいる
- YouTube や Spotify などオンラインで音楽を聴いている
- 出会いの頻度は週に数回程度

## ユーザーの行動・習慣

- 日常的にオンラインで音楽を聴いている
- 主な利用環境は **PC のブラウザ**
- 新しい曲との出会い方:
  - ブログや SNS をザッピングしていて紹介される
  - YouTube のおすすめに出てくる
  - Spotify のレコメンドがきっかけになることはほぼない
- 出会いから記録までの流れ:
  1. 曲に出会う（SNS, ブログ, YouTube など）
  2. 「どんなアーティストだろう？」と Web 検索する
  3. 紹介記事・Wikipedia・アーティストプロフィールなどを見る
  4. 関心が増幅され、「記録しておこう」となる
- 記録の粒度には2パターンある:
  - **即時キャプチャ:** 出会いの瞬間に URL だけさっと保存する。曲名やアーティスト名は後回し
  - **じっくり記録:** 調べた後に、曲名・アーティスト名・メモ・タグも含めて記録する
- 未補完の記録（URL のみ）は、数日後や週末などにまとめて情報を整理する運用も許容される
- 同じ曲に再び出会うことがある。その場合「またこの曲に出会った」ことを日付とともに記録したい
- 記録する URL はほとんどの場合 YouTube。見つからなければ Spotify 等の代替リンクを使う。基本的に1つあれば十分
- 数年後に URL がリンク切れになる可能性がある。その場合は手動で別の URL（Spotify 等）に貼り替えて対応する
- その日知った曲のリンクを SNS（主に Facebook）に投稿している
- SNS 投稿は今後も続ける。このツールを使い始めても、直接 SNS に投稿してしまうことはある
- スマホでも SNS 経由で出会うことはあるが、アーティスト情報を調べるのが面倒で、関心が増幅されず記録に至らないことがある

## 課題・困っていること

- 出会った曲をデータベース化していない
- 自分がいつどんな曲に出会ったかを覚えていない
- 後から振り返る手段がない
- SNS への投稿は流れてしまい、蓄積・検索に向いていない

## やりたいこと（ニーズ）

- 出会った曲を記録として残したい
  - 残したい情報: 曲名、アーティスト名、タグ・分類、ひとことメモ、記録日時、URL
  - 動画 URL などから情報を自動収集し、入力の手間を省きたい
  - URL だけ先に記録しておき、曲名・アーティスト名は後からまとめて補完したい
  - 記録した情報はいつでも自由に更新したい
- 後から検索して振り返りたい
  - 日付で辿る（「あの時期何を聴いていたか」）
  - アーティストで探す（「このアーティストの他に何を聴いたか」）
  - 気分・シーンで探す（「作業BGMに良かった曲は何だったか」）
- 振り返りをきっかけに、同じ曲をまた聴いたり、同じアーティストの他の曲を探したい

## Job Statement（JTBD）

> **新しい曲に出会ったとき**、その感動とリンクを手間なく記録して自分だけのアーカイブに残したい。
> そうすれば、数ヶ月後・数年後でも「あの時期何にハマっていたか」を振り返り、そこからリスニング体験を広げられる。

### 補足: 現状のワークアラウンドと限界

| 代替手段 | 限界 |
|----------|------|
| SNS に投稿 | 蓄積・検索に向いていない。投稿が流れてしまう |
| 記憶 | 忘れる |

核心的な問題: **「SNS投稿というアウトプット」と「検索可能なデータベースへの保存」が分断されている**こと。

### 補足: SNS との関係

- SNS（Facebook）への投稿は今後も併用する。このツールが SNS を置き換えるわけではない
- 過去の Facebook 投稿に音楽リンクが蓄積されており、取り込みたい
- このツール導入後も SNS に先に投稿してしまうことがあるので、SNS 投稿をたまにこのアプリに取り込む手段がほしい
- 記録時にこのアプリから SNS に投稿できると嬉しいが、オプショナル

## ペインポイントの時間推移

ユーザー体験を時間軸で整理し、感情の落差とペインの所在を可視化する。

```
出会い           調べる           関心増幅        共有            数日後           振り返り時
  😊 興味  →  🤔 探索  →  😊 ワクワク  →  😊 満足  →  😟 もどかしい  →  😔 諦め
  ──────────────────────────────────────────────────────────────────────────────────
  SNS/ブログ/     Web検索で       紹介記事等を      SNSに投稿     曲名を忘れる      検索手段がない
  YouTubeで       アーティスト    読んで関心が      （ここで       SNSを遡るのが     深掘りの
  曲に出会う      を調べる        増幅される        データが       面倒              機会を損失
                                  →記録しよう       流れ始める）

  ※スマホでは「調べる」が面倒 → 関心増幅に至らず、記録されずに終わることがある
```

**最大のペインポイント: 「数日後」のフェーズ。** 出会いの高揚感が冷めた後、記録がないことに気づくが、もう手遅れ。このギャップを埋めるには「出会いの瞬間」に最小限の手間で記録できる仕組みが必要。

### 利用環境の補足

- **PC ブラウザが主戦場。** 出会い → 調べる → 関心増幅 → 記録、の一連の流れが PC 上で完結する
- スマホは将来的に「アプリでシェア」の導線で連携できると理想的だが、MVP では PC ブラウザ優先で十分
